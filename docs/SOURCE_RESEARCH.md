# Manga source research, 19 November 2026

Research-first register. Website availability, an API, or a viewer does **not** grant bulk downloading or public artefact redistribution rights. These are research classifications, not implemented remote adapters.

| Candidate | URL and supported reference | Evidence / access | Quality, discovery and constraints | Decision |
| --- | --- | --- | --- | --- |
| Pepper&Carrot | https://www.peppercarrot.com/en/webcomic-sources/ep26_Books-Are-Great.html | The official episode offers high-resolution compiled pages and episode-specific CC BY 4.0 attribution; direct links and source git directories are presented. Authors and translation credits vary per episode/language. | PNG/JPEG renderings and source KRA/SVG; episode/page discovery from source pages. No promised unlimited API or live reliability checks. Use controlled small requests with per-episode licence evidence. | **Enabled for episode 26 only**; experimental licensed adaptor implemented with official high-resolution pages, other episodes unimplemented. |
| MangaDex | https://api.mangadex.org/docs/ and https://gitlab.com/mangadex-pub/mangadex-api-docs | Published API and acceptable-use policy. These do not independently license chapter-page permanent archives. API terms and CDN limits must be reviewed for each use. | Rich series/chapter metadata, language/scanlation distinctions and rate-limited JSON; image-download grant and long-term archival rights not verified. No credentials configured. | **Metadata-only research**; no image fetch. |
| National Diet Library | https://www.ndl.go.jp/en/use/reproduction and https://www.ndl.go.jp/en/imagebank/about | NDL confirms works marked copyright-expired (インターネット公開（保護期間満了）) are public domain. Other access categories need rightsholder consent. Image Bank material is public domain with attribution requested. | Selected old Japanese images via public collection interface, title/image metadata and sometimes IIIF; modern manga availability not established. Each image/volume rights status must be checked. | **Experimental, item-specific**; no scraper. |
| ComicFury | https://comicfury.com/tos.php | Standard site terms permit only transient personal viewing, not permanent archiving. Creator retains copyright and may separately license own work, subject to platform restrictions. | Creator comics, varying formats and metadata; no general authorised chapter export mechanism confirmed. | **Unsupported by default**, explicit creator/platform authorisation required. |
| Wikimedia Commons | https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en | File-by-file public-domain/open licences, original-resolution downloads and mandatory attribution where applicable. | Broad image and book scans rather than a uniform chapter catalogue; provenance and per-file licence must be preserved. | **Experimental, item-specific local import**, no automated adapter. |
| Official publishers and creator-hosted media | Publisher/creator’s official site, individually verified | Explicit export permission or written rightsholder consent required. Ordinary online reading offers insufficient proof. | Discovery, format, authentication, limits and reliability depend on each agreement. | **Unsupported until documented authorisation**. |

Evidence checked: [Pepper&Carrot official source page](https://www.peppercarrot.com/en/webcomic-sources/ep26_Books-Are-Great.html), [MangaDex API docs](https://gitlab.com/mangadex-pub/mangadex-api-docs/-/blob/main/index.md), [NDL reuse rules](https://www.ndl.go.jp/en/use/reproduction), [ComicFury terms](https://comicfury.com/tos.php), [Wikimedia reuse](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en).

**Required before activating an adaptor:** record exact licence at episode/chapter/image level; check changes to host terms and acceptable-use rules; prove page discovery and download permission with a small authorised test; specify allowed endpoints, formats, authentication, network limits, retries, and hosting/artefact disclosure policy. Do not imply that a successful metadata API call demonstrates downloadable manga content.
