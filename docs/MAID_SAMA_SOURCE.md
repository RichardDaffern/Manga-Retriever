# Maid-sama! source feasibility

- **Manga:** *Kaichou wa Maid-sama!* (also *Maid-sama!*), Hiro Fujiwara.
- **Official licensed English edition:** https://www.viz.com/maid-sama . This is a legitimate purchasing/reading option; the VIZ online listing does **not** prove downloadable unprotected image access.
- **Candidate community-language listing:** https://mangadex.org/title/d5e2bd89-e300-4262-a799-fb4f79bdb777/kaichou-wa-maid-sama
- **Main series:** commonly catalogued as 85 numbered chapters plus extras, including later bonus material; verify counts against source feed.
- **Live check:** [Maid-sama English MangaDex Availability Probe](../.github/workflows/maid-sama-source-probe.yml) fetches public title metadata and paginates the English feed, measures chapter coverage, and emits a seven-day *metadata-only* report. This does not retrieve page images or establish image quality.
- **Download decision:** Only consider a bounded local, rights-reviewed pilot once English chapter coverage and source permissions are established. No public media artefacts or MangaDex image downloads are authorised by this document.
- **ReLIFE:** existing all-chapter GitHub Actions batch run is independent; this probe does not modify its jobs or media retrieval behaviour.
